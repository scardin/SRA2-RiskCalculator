# SRA2 Calculateur de Risque

A minimalist, web-based probability calculator tailored for the Shadowrun Anarchy RPG. 

**Note:** This tool is currently a **French-only** version, as it utilizes the specific terminology (e.g., "Incompétent", "Dieu", "Désavantage") from the French translation of the Shadowrun Anarchy v2.0 sourcebook.

## Core Features
* **Dice Pool & Risk:** Computes probabilities for dice pools ranging from 1 to 16 dice, integrating Risk Reduction (RR 0-3) and Situational modifiers (Avantage, Neutre, Désavantage) directly into the success calculations.
* **Instant Probability Matrix:** Displays exact success thresholds (Facile 2+, Difficile 4+, Ardue 6+, Extreme 8+) and cumulative failure complications (Aucune 0, Mineure 1+, Critique 2+, Désastre 3+).
* **Dynamic Color Coding:** Utilizes a tier-based color-coding system (Black, Blue, Green, Yellow, Red, Purple) to instantly visualize probability density, risk severity, and dice pool labels.


## Usage
**Live Access:** You can use the calculator directly via the GitHub Pages Link Here:

https://github.com/scardin/SRA2-RiskCalculator

**Local Use:** Alternatively, clone the repository and open the `index.html` file in any modern web browser. The calculator operates entirely client-side, requiring no external dependencies, server-side processing, or build steps.
